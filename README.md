# Hi, I'm Luiz 👋
### Data Engineer · Analytics — Credit & Risk @ Porto Bank

I'm a Brazilian Data Engineer working mainly with data pipelines, analytics engineering, and data analysis for credit and ecommerce.

My background is a mix of analytics work and hands-on data engineering. I have worked on dashboards, process optimization, and analyses for a credit engine at a large bank, and I build the pipelines — ingestion, transformation, and orchestration — that feed that analysis.

I like building data systems that are not just dashboards: systems that need to move data reliably, model it correctly, run on schedule, and hold up once real business decisions depend on them.

Some areas I especially enjoy:

* Building ELT pipelines from raw ingestion to modeled marts (dbt + Snowflake)
* Orchestrating and monitoring data workflows with Airflow
* Designing data models that hold up under changing business rules
* Turning ad-hoc analysis into repeatable, production-grade pipelines
* Working across data, engineering, and business stakeholders

## 🚀 Featured projects

### 🔧 E2E Pipeline — API → S3 → Snowflake → dbt → Airflow
Full data engineering pipeline built with daily commits: Python extraction, a raw layer partitioned by date in S3, load via stage/COPY INTO in Snowflake, staging/mart modeling in dbt, and orchestration with Airflow. CI via GitHub Actions.
`Python` `Snowflake` `dbt` `Airflow` `Docker` `GitHub Actions`

### 📈 Parâmetros Hub
Internal web app for the my team at Porto Bank, featuring an OKR tracking dashboard (lead time and ticket volume) for the Params and Credit Engine areas.
`Google Apps Script`

### ⚡ Pandas vs Polars vs PySpark — Performance Benchmark
Benchmark project comparing the three most-used data manipulation tools by running identical heavy transformations (filtering, groupby, joins, window functions, sorting, string ops) across synthetic and public datasets. Tracks execution time and memory usage across repeated cold/warm runs to measure real performance limits, containerized with Docker for reproducibility.
`Python` `Pandas` `Polars` `PySpark` `Docker`
